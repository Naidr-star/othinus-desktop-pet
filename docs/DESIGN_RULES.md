# 角色与动作设计规则

本文件是后续美术、动作和显示逻辑的长期约束。除非用户明确批准改变母模型，否则这些规则优先于临时生成结果。

## 角色基准

- 当前选定母模型是候选 03 的方向，并在其基础上进一步采用圆润 Q 版画风。
- 母模型文件：`assets_v2/othinus_master_v2_transparent.png`。
- 运行时站立基准：`assets/sprites_v2/idle_neutral.png`。
- 站立姿势约 2.7 头身，保持修长，不得横向发胖或把腿部再次缩短。
- 所有动作必须看起来是同一人物、同一套服装和同一套绘制体系。

## 必须保持的识别特征

- 巨大宽檐帽、眼罩、可见绿色眼睛、浅金色长发、黑白红披风式服装。
- 帽子、披风、领口、袖口和腿部结构应以现有母模型及当前 `idle_neutral` 为准。
- 发色以日常立正待机的淡浅黄色为准，不得变成高饱和亮金色或橙黄色。
- 线稿、阴影和赛璐璐上色强度应与当前日常图集一致。

## 禁止的外观漂移

- 不改成黑绿配色或通用奇幻女巫服。
- 不增加羽毛、夸张金色帽饰、原模型没有的内衬衣或短裤。
- 不随动作改变年龄感、脸型、瞳色、眼罩方向和发型主体。
- 不因单张动作构图而独立放大或缩小人物，避免动作切换时视觉体型跳变。
- 不使用与当前角色不同的厚重写实、低幼扁平或高饱和霓虹画风。

## 尺寸、锚点和透明轮廓

- 角色运行画布固定为透明正方形精灵，程序统一绘制为相同感知尺寸。
- 人物脚部和身体中心必须围绕统一锚点组织；动作差异来自姿势，不来自整体缩放。
- 帽尖、帽檐、头发、披风、鞋、武器和特效必须完整保留在 PNG alpha 轮廓中。
- 九宫格图集切分时必须按主体完整轮廓提取，不可只按机械格线裁切。
- 新素材加入后必须在最大桌宠缩放下验证透明窗口四边仍有安全余量。
- 不通过缩小整个人物来掩盖单张素材越界；应修复源轮廓或安全画布。

## 动作与表情

- 一个逻辑动作可以对应多个表情或姿势，但不得为了数量牺牲模型一致性。
- 日常动作应覆盖待机、微笑、得意、摸头、害羞、困惑、惊讶、生气、哭泣、进食、喝茶、哈欠、大笑、发呆和赠礼。
- 动作驻留时间要足以让用户看清，切换使用平滑淡化；禁止快速闪烁式轮换。
- 静止待机不得持续让整个人物上下抖动或平移。
- 只有步行、跳跃、睡眠呼吸等有明确语义的动作可使用轻微局部运动。
- 自动移动必须显示自然步行姿势，并保持低频、短距离和二维变化。

## 拖动与屏幕边缘

- 人物被拖动时使用参考“被斯芬克斯叼起”的悬垂姿势，但画面中不得出现猫。
- 人工拖动必须抢占窗口位置，自动散步不得与其同时运行。
- 边缘行为只在人物真实可见轮廓接近边缘时触发，不按透明窗口外框触发。
- 扶墙、探头等动作应刚好接触对应边缘，不得浮空。
- 左右动作必须根据目标边缘正确镜像；切换边缘动作后重新校正真实轮廓。

## 主神之枪

- 外观保持金色叶片镂空枪头、分枝符文护部、扭曲枪身和根状尾端。
- 独立漂浮神枪与人物重叠时始终绘制在人物下层。
- 神枪位置使用相对人物的局部坐标，拖动人物后相对关系保持不变。
- 默认角度为 8°，默认尺寸为旧基础尺寸的 125%；用户可在 65%～145% 之间调整。
- 任意角度和允许尺寸下都不得超出透明窗口边界。
- 使用内嵌神枪的战斗精灵时应隐藏独立漂浮神枪，避免出现两把武器。

## 睡眠与上条当麻玩偶

- 睡眠姿势可以侧卧或坐睡，披风自然包裹身体。
- 上条当麻 Q 版玩偶保持刺猬黑发、白色短袖衬衫、橙色内搭和深色长裤等关键特征。
- 玩偶是抱枕/软玩偶比例，不能抢占欧提努斯主体身份。

## 图标

- 当前程序与托盘图标是透明背景的欧提努斯全身图，不是旧版头像近景。
- 图标必须在 16、24、32、48、64、128 和 256 像素下保持可识别。
- 不回退到旧错误模型、旧头像图标或不透明背景。

## 文案与作品气质

- 互动语气应体现魔神的自信、毒舌、戏谑和对“理解者”的亲近。
- 作品元素应自然进入玩法，不用与角色无关的通用小游戏或生硬标题跳脸。
- 世界终结演出可以使用原创的仿作风格宣誓，但不得大段复制原作文本。

## 新素材验收清单

1. 与 `idle_neutral` 并排比较头身比、腿长、脸型、发色和衣着。
2. 在透明背景上检查完整 alpha 轮廓和孤立噪点。
3. 在程序最大缩放下渲染动作全过程，检查帽子、脚、披风和武器。
4. 检查动作切换前后人物感知尺寸和脚下锚点。
5. 检查左右镜像、边缘贴合和神枪层级。
6. 通过自动验证后再进行实际桌面观察。
