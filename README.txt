欧提努斯桌宠 v2.6.2
===================

启动方式
--------
双击桌面的“欧提努斯桌宠.exe”。程序运行后会在系统托盘（桌面右下角）显示角色图标。

基础互动
--------
单击角色：摸摸头
双击角色：释放符文魔法
拖动角色：移动到桌面任意位置
鼠标滚轮：调整桌宠大小
右键角色：打开完整互动菜单
单击托盘图标：显示或隐藏桌宠
右键托盘图标：投喂、玩耍、随机表情、主神之枪、战斗、休息、桌面小游戏、今日神谕、毁灭世界演出等

动作与表情
----------
内置32张角色精灵，包括多种待机、微笑、得意、摸头、害羞、困惑、惊讶、生气、哭泣、
吃饼干、喝茶、打哈欠、大笑、发呆、赠礼、魔法、战斗、悬垂拖动、步行和屏幕边缘动作。
同一动作会随机选用多个表情变体，例如待机、摸头、进食、魔法和睡觉均不只一种画面。

主神之枪
----------
右键菜单可召唤主神之枪或进行战斗演练。
“主神之枪常驻漂浮”开启后，非战斗动作中神枪会漂浮在欧提努斯身边。
进入“主神之枪调整”子菜单并选择“调整主神之枪位置”后，可在桌宠画布内直接拖动神枪；再次
选择“完成主神之枪调整”即可固定相对位置。“输入主神之枪角度…”支持 -180°～180°，尺寸可在
65%～145% 之间自定义，默认值为 125%，并可一键恢复默认位置、角度和尺寸。
神枪会随人物整体拖动并随桌宠比例缩放；与人物重叠时位于人物贴图下方。
战斗动作包括备战、突刺、旋转、守护、胜利和力竭等状态。

睡觉互动
----------
右键选择“休息一下…”后，可选择 1、5、15 分钟，或自定义 1～180 分钟。
睡觉会随机进入两种抱枕姿势，欧提努斯会抱着上条当麻Q版玩偶休息。
精力越低，角色越容易主动休息；低于 18 时通常休息 3～5 分钟，接近耗尽时会休息 5～7 分钟。
休息期间持续恢复精力，单击角色或选择其它互动可以提前叫醒她。

世界终结演出
------------
右键选择“毁灭世界（演出）”，欧提努斯会举起主神之枪，触发跨屏的世界崩坏与重启动画。
演出结束后她会承认这只是对理解者开的玩笑。此功能只有画面效果，不会修改系统或用户文件。

今日神谕
--------
每天可让欧提努斯给出一条当天固定的小神谕；累计互动还能解锁“神谕记录者”等新成就。

成长系统
--------
互动可获得经验和亲密度，升级会获得饼干币、相位碎片并解锁更高称号。
饱食度、精力和心情会随时间变化；投喂、休息和玩耍可恢复状态。
亲密度会依次提升“初次相遇”至“唯一的理解者”等六个羁绊阶段，羁绊越深，小游戏奖励越高。
每日见面会累计连续相伴天数；每三天可获得额外相位碎片，断签后从第一天重新累计。
符文追迹、主神之枪、相位记忆拥有独立熟练度与纪录。熟练度提升后会扩大有效点击区、
放宽神枪共鸣区或延长相位显现时间。成长档案会显示所有进度、纪录、近期成就与解锁能力。
五枚相位碎片可进行一次“相位馈赠”，恢复饱食、精力和心情并增加亲密度。

桌面内小游戏
------------
所有小游戏直接覆盖在桌宠透明窗口中，欧提努斯仍会显示对应动作，不再打开额外游戏窗口。
北欧符文追迹：追逐移动的金色符文，连续命中可提高得分；点到暗红伪符文会扣分并中断连击。
主神之枪校准：移动指针进入金色共鸣区时点击，共进行六击，命中中央白色区域可获得完美校准。
相位记忆：记住四枚相位依次亮起的顺序，再按相同顺序复写；熟练度提高后序列会逐步增长。
完成游戏可获得经验、饼干币、亲密度、对应熟练度和相位碎片，并可能解锁专属成就。
